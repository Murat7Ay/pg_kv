# pg_kv benchmark — 20261019-012615

PostgreSQL 18.6 (Debian 18.6-1.pgdg13+2) and Redis 8.10.2, each server limited to 4 CPUs; clients in separate 3-CPU
containers over the compose network (host: 8 CPUs). 16 clients / 3 client threads,
100k keys, 64-byte values. Median of 3 rounds (15s per Postgres run, 600000 requests per Redis test).
